# Indonesian National Heroes Directory

A simple, interactive command-line application written in Python that provides a comprehensive directory of Indonesian national heroes. This project serves as an educational tool to learn about the historical figures who fought for Indonesia's independence and sovereignty.

## 🚀 Features

* **Interactive CLI Menu:** Dynamically generated numeric menu for easy navigation.
* **Comprehensive Profiles:** Displays detailed information for each hero, including:
  * Place of Origin
  * Historical Role
  * Major Legacy & Struggle
* **Robust Error Handling:** Protects the application from crashing due to invalid numeric inputs or typos.
* **Scalable Database:** Structured using nested Python dictionaries, making it effortless to add more heroes over time.

## 🛠️ Prerequisites

To run this application, you only need to have Python installed on your system. It does not require any external third-party libraries.

* Python 3.x

## 💻 How to Run

### Running Locally (PC / Mac / Linux)

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd YOUR-REPO-NAME
   ```
3. Run the application:
   ```bash
   python pahlawan.py
   ```

### Running on Mobile (Termux)

If you are using Termux on Android, make sure you have Python installed:
```bash
pkg install python
python pahlawan.py
```
